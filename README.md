# Гомель ↔ озеро Комо · 14 дней

Автомаршрут для **Volkswagen Tiguan Allspace 2.0 TDI DFGA** / **DQ381**. Виза с **11 октября 2026**, финиш **24 октября**. Больше ночей в Италии, сжатый транзит, крупные аутлеты по пути.

## Календарь

| Когда | Что |
| --- | --- |
| 11.10 | Гомель → Белосток |
| 12.10 | Белосток → Инсбрук (Чехия транзитом; аутлеты Warszawa + Freeport) |
| 13.10 | Инсбрук → Комо |
| 13–21.10 | **9 ночей в Италии** (Serravalle, Franciacorta, озеро) |
| 22.10 | Комо → Мюнхен (Ingolstadt Village) |
| 23.10 | Мюнхен → Белосток (Fashion House Wrocław) |
| 24.10 | Белосток → Гомель |

Чехия — без ночёвки. Австрия — одна ночь в Инсбруке (иначе день 2 становится 14–15 часами с шопингом).
